Projeto acadêmico de gestão hoteleira em **C#**, **Windows Forms**, **.NET 8** e **MySQL**.

## Funcionalidades identificadas no projeto original

- Boas-vindas e autenticação.
- Cadastro de clientes.
- Menu de navegação.
- Consulta de informações.
- Reserva de quartos e cancelamento de reservas.

## Estrutura prevista

```text
Hotel/
├── BancoDeDados/        # conexão MySQL
├── Telas/               # formulários, designers e recursos
├── Properties/          # recursos do projeto
├── Resources/           # imagens
├── BancoHotel1.sql      # estrutura de banco
├── Hotel.csproj
├── Hotel.slnx
└── Program.cs
```

## Execução

Use **Visual Studio 2022** com suporte a desenvolvimento desktop .NET, **SDK .NET 8** e **MySQL Server**. Abra a solução `Hotel.slnx`, configure a conexão MySQL em ambiente local, restaure os pacotes NuGet e execute.

> **Situação da publicação:** este README é a primeira etapa. A transferência dos arquivos de código, formulários e imagens do ZIP original está pendente. O sistema ainda não pode ser compilado a partir deste repositório.

> **Segurança:** não publique senhas de banco de dados. Revise as configurações de conexão antes de disponibilizar o projeto para terceiros.
